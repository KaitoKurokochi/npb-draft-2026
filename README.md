# npb-draft-2026

NPB 2026年ドラフト会議の1位指名予想プロジェクト。

各球団のロースター現状分析・過去ドラフト傾向・2026年候補選手評価を組み合わせて、12球団の1位指名を予想する。

## アプローチ

1. **ロースター分析** — 各球団の支配下選手をポジション別・年齢別・成績別（野手はOPS、投手は先発/中継ぎ/抑え）に整理し、穴を特定
2. **ニーズ判定** — 即戦力（大卒・社会人）vs 育成（高卒・5年後基準）の優先度を決定
3. **過去ドラフト傾向** — 過去5〜7年の1位指名パターンを球団別に分析
4. **候補選手評価** — 2026年の上位候補をポジション・カテゴリ別にリスト化
5. **予想まとめ** — ニーズ × 傾向 × 候補をマッチングして12球団を予想

## ディレクトリ構成

```
npb-draft-2026/
├── src/
│   ├── build_view.py  # 年齢×ポジションの戦力表 (HTML) を作成・編集
│   ├── derive.py      # 年齢・役割・守備位置・レギュラー判定などの導出（純粋関数）
│   ├── npb_db.py      # npb_scraper のデータベース (npb.sqlite) を読み取り専用で読む
│   └── fetch.py       # （旧）Yahoo/NPB.jp から名簿を取得して rosters/*.md に書く。npb_scraper に置き換わり、現在は使わない
├── notebooks/         # 探索的分析・可視化
├── results/           # 分析結果 (git管理外)
├── figures/           # 図表 (git管理外)
└── README.md
```

データは**リポジトリの外**（iCloud）に置く。環境変数 `NPB_DATA` で場所を指定する（`~/.claude/.agent_home` で設定）。

```
$NPB_DATA/npb_scraper/npb.sqlite     # 選手・成績（npb_scraper が作る。このリポジトリは読むだけ）
$NPB_DATA/npb-draft-2026/
├── roster_view.html   # 戦力表（build_view.py の出力）
├── overrides.json     # ドラッグで変えた守備位置・投手の役割 {player_id: {position|role}}
├── labels.json        # 「まだ数年使える」ラベル [player_id]
├── candidates/        # 2026年候補選手データ
└── past_drafts/       # 過去ドラフトデータ
```

## 使い方

```bash
pip install -r requirements.txt
```

### 1. データを用意する

選手・成績は `npb_scraper` リポジトリ（`$REPOS/npb_scraper`）が `$NPB_DATA/npb_scraper/npb.sqlite` に作る。取得・更新の方法はそちらの README を参照。

### 2. 戦力表を見る (`build_view.py`)

```bash
python3 src/build_view.py             # roster_view.html を書き出す（閲覧のみ）
open "$NPB_DATA/npb-draft-2026/roster_view.html"
```

12球団のタブがあり、行が来年開幕時の年齢、列が先発・中継ぎ/抑え・捕手・内野の各ポジション・外野手。明るい文字がレギュラー（基準は `src/build_view.py` 冒頭の定数）。

### 3. 選手のポジションを動かす（ドラッグ編集）

```bash
python3 src/build_view.py --serve     # 起動。Ctrl+C で停止
open http://127.0.0.1:8765/
```

- 選手を別の列にドラッグすると、その選手の `position`（投手は `role`）が `overrides.json` に保存される。動かせるのは、同じ年齢の行の中で、同じ種類の列どうしだけ
- 自動判定の値は変わらず、元の列に戻すと上書きが消える
- 選手名をクリックすると「まだ数年使える」ラベル（緑）の付け外し。`$NPB_DATA/npb-draft-2026/labels.json` に保存される
- サーバーはこのPCの中（127.0.0.1）だけで動く。ページの再読み込みで最新の表になる

## データソース

- **ロースターデータ**: Yahoo!スポーツナビ（球団ページの選手一覧・打撃成績・投手成績、投手の個人ページ）。**支配下選手のみ**を対象にする（育成まで見ると量が多すぎるため）。詳細は `$DOCS/agent/baseball/npb_draft_2026.md`
- **過去ドラフトデータ**: NPB公式 / Webスクレイピング or 手動入力
- **候補選手データ**: 球歴.com・ベースボールマガジン・各スポーツ紙等
